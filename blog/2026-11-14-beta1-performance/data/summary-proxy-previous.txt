- VM: `Standard_F8als_v6` (8 vCPU / 16 GB), Debian 12, Korea South

- Proxy mode (`proxy=true`), 10 samples per point, 3 warmups excluded

## Notes

- Times are mean total runtime in seconds; deltas are `(tip - old) / old`.
- `app_latency` defaults to 50 ms because the configs don't set it. This applies to both modes and both builds.
- On the tip-native latency CSV, some 75–200 ms rows record ~0.59 MB uploaded instead of ~0.72 MB; old-native and both WASM runs stay constant. It looks like a proxy byte-accounting race in the tip branch, not a timing issue.
- Both harness versions write a CSV header that starts at `time_total` instead of the full 18 columns. Data rows contain all 18 fields; the summaries parse by column position.
